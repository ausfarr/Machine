# Dashboard

A static React + Vite + Tailwind site showing real pipeline status, read
from the data file Ledger writes (`dashboard/public/status.json`).
Deployed as a static build via GitHub Pages (wired up in step 7).

## Usage

```
cd dashboard
npm install
npm run dev       # local dev server
npm run build     # typecheck + static build to dashboard/dist
```

The dashboard fetches `status.json` at runtime — it does not compute
anything itself. Before running `dev`/`build`, refresh the data from the
repo root:

```
npm run ledger
```

If `status.json` is missing or stale, the dashboard shows an explicit
error telling you to run Ledger — it never falls back to placeholder
data.

## Guardrail

Every number and batch on this page comes directly from
`dashboard/public/status.json`, which Ledger generates directly from
batch manifests. No fabricated or demo data is ever hard-coded into the
UI — an empty pipeline renders an honest "no batches yet" state instead
of sample content.

## Structure

- `src/App.tsx` — the whole dashboard (summary stats + per-batch cards)
- `src/types.ts` — mirrors `agents/ledger/index.ts`'s output shape
- `public/status.json` — generated by Ledger, not hand-edited
